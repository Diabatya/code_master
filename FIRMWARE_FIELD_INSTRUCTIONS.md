# Инструкция для мастера: первая прошивка и настройка платы CodeMaster

Инструкция рассчитана на человека, который просто должен прошить плату и настроить имя/серийный номер. Технические детали протоколов и адресов приведены только там, где они нужны для правильного выбора в программе.

---

# 1. Что нужно скачать

Откройте релиз:

```text
https://github.com/Diabatya/code_master/releases/tag/latest
```

Скачайте:

## Для Windows

```text
CodeMaster.exe
```

Это основной конфигуратор.

## Файлы прошивки

```text
codemaster_bootloader.hex
codemaster_app.hex
```

Также есть BIN-файлы, но для первой прошивки лучше использовать HEX:

```text
codemaster_bootloader.hex
codemaster_app.hex
```

HEX уже содержит правильный адрес записи. Адрес вручную вводить не нужно.

---

# 2. Что прошивать в зависимости от состояния платы

## Вариант 1. Плата уже работает и определяется как CodeMaster

Если плата уже подключается к компьютеру и определяется как USB CodeMaster, bootloader уже установлен.

В этом случае нужно прошить только:

```text
codemaster_app.hex
```

Bootloader повторно прошивать не нужно.

Переходите сразу к разделу 4.

---

## Вариант 2. Плата новая или полностью пустая

Если плата новая, не определяется как CodeMaster и в ней нет загрузчика, сначала нужно установить bootloader, затем основное приложение.

Понадобится программатор **ST-Link** и программа **STM32CubeProgrammer**.

---

# 3. Первая прошивка новой платы через ST-Link

## 3.1. Подключение ST-Link

Подключите ST-Link к плате:

| ST-Link | Плата |
|---|---|
| SWDIO | SWDIO |
| SWCLK | SWCLK |
| GND | GND |
| 3.3V | 3.3V или питание платы |
| NRST | RESET, если используется |

Питание платы должно быть включено.

## 3.2. Запись bootloader

1. Запустите **STM32CubeProgrammer**.
2. В правом верхнем углу выберите:
   ```text
   ST-LINK
   ```
3. Нажмите кнопку подключения.
4. Откройте файл:
   ```text
   codemaster_bootloader.hex
   ```
5. Нажмите **Download** или **Program**.
6. Дождитесь окончания записи и проверки.

Bootloader должен записаться в начало памяти платы. Для HEX адрес уже находится внутри файла.

**Не нажимайте полное стирание после записи bootloader.**

## 3.3. Запись основной прошивки

1. Не отключая ST-Link, загрузите:
   ```text
   codemaster_app.hex
   ```
2. Нажмите **Download** или **Program**.
3. Дождитесь окончания записи и проверки.
4. Отключите питание платы.
5. Установите:
   ```text
   BOOT0 = 0
   ```
6. Снова включите питание или нажмите RESET.

После этого плата должна запуститься как обычное устройство CodeMaster.

---

# 4. Если плата уже имеет bootloader

Для обычного обновления используйте только:

```text
codemaster_app.hex
```

Не записывайте его с начала памяти вручную.

Если используется BIN, адрес приложения должен быть:

```text
0x08008000
```

Но предпочтительнее использовать HEX.

---

# 5. Настройка имени и серийного номера

После прошивки основной application firmware:

1. Подключите плату обычным USB-кабелем.
2. Запустите `CodeMaster.exe`.
3. Откройте вкладку:
   ```text
   Прошить микроконтроллер
   ```
4. В поле **Способ программирования** выберите:
   ```text
   Авто
   ```
   или:
   ```text
   USB (CDC bootloader)
   ```
5. Нажмите **Подключиться**.
6. Введите:
   ```text
   Устройство
   Серийный номер
   ```
7. Не добавляйте файл прошивки в список файлов.
8. Включите кнопку:
   ```text
   Записать конфигурацию устройства
   ```
9. Нажмите **Прошить**.

В этом режиме приложение должно записать только имя и serial. Основная прошивка не перезаписывается.

После записи устройство может на короткое время отключиться от USB и подключиться заново. Это нормально.

Зелёная кнопка **Подключено** после этого должна вернуться в обычное состояние **Подключиться**.

---

# 6. Проверка имени и serial

После записи конфигурации:

1. Подождите повторного появления USB-порта.
2. Нажмите **Подключиться**.
3. Нажмите:
   ```text
   Прочитать конфигурацию
   ```
4. Убедитесь, что имя и serial отображаются правильно.

Если имя и serial прочитались — настройка завершена.

---

# 7. Прошивка через USB DFU

Этот способ нужен, если плата находится в системном режиме STM32 DFU.

## 7.1. Перевод в DFU

1. Установите:
   ```text
   BOOT0 = 1
   ```
2. Нажмите RESET или переподключите питание.
3. В Windows должно появиться устройство:
   ```text
   STM32 BOOTLOADER
   VID 0483, PID DF11
   ```

Если устройство не найдено, установите драйвер WinUSB/libusb через STM32CubeProgrammer или Zadig.

## 7.2. Запись application

В `CodeMaster`:

1. Выберите:
   ```text
   USB (DFU)
   ```
2. Добавьте:
   ```text
   codemaster_app.hex
   ```
3. Для первой записи новой application не включайте запись конфигурации.
4. Нажмите **Прошить**.
5. Дождитесь записи и проверки.
6. Установите:
   ```text
   BOOT0 = 0
   ```
7. Нажмите RESET.

Текущая версия DFU пишет application значительно быстрее старой версии.

---

# 8. Прошивка через USB CDC bootloader

Если устройство определяется как:

```text
CodeMaster Bootloader
VID 0483, PID 5741
```

1. В `CodeMaster` выберите:
   ```text
   USB (CDC bootloader)
   ```
2. Добавьте файл:
   ```text
   codemaster_app.hex
   ```
3. Нажмите **Прошить**.
4. Дождитесь завершения.
5. После перезапуска устройство должно появиться как application.

---

# 9. Прошивка через UART

Если используется USB-UART адаптер:

1. Установите драйвер адаптера:
   - CH340/CH341;
   - CP210x;
   - FTDI.
2. Подключите RX/TX/GND.
3. Переведите плату в bootloader согласно схеме платы.
4. В `CodeMaster` выберите:
   ```text
   UART (бутлоадер)
   ```
5. Выберите COM-порт.
6. Добавьте:
   ```text
   codemaster_app.hex
   ```
7. Нажмите **Прошить**.

Обычно используется скорость:

```text
115200
```

---

# 10. Что означает кнопка «Проверять после записи»

Если кнопка включена, конфигуратор после записи читает данные обратно и сравнивает их с файлом.

Рекомендуется оставить её включённой при первой прошивке.

Если запись проходит слишком долго, её можно временно отключить после того, как устройство уже проверено.

---

# 11. Кнопка «Стереть Flash»

Кнопку **Стереть Flash** без необходимости не нажимать.

Она нужна только для полного восстановления платы.

В зависимости от выбранного способа может быть стёрто:

- приложение;
- bootloader;
- конфигурация;
- триггеры.

После полного стирания плату нужно будет прошить заново через ST-Link или STM32CubeProgrammer.

Для обычного обновления используйте **Прошить**, а не **Стереть Flash**.

---

# 12. Если появляется ошибка «USB DFU устройство не найдено»

Проверьте по порядку:

1. BOOT0 действительно установлен в `1`.
2. После установки BOOT0 нажата кнопка RESET.
3. Используется USB-кабель с линиями данных.
4. В диспетчере устройств есть:
   ```text
   STM32 BOOTLOADER 0483:DF11
   ```
5. Установлен WinUSB/libusb-драйвер.
6. Закрыт STM32CubeProgrammer и другие программы, которые могут занимать DFU.
7. Переподключено питание платы.

---

# 13. Если появляется ошибка при чтении конфигурации

Сообщение о старой или неинициализированной конфигурации означает, что на плате ещё нет новой config page.

Порядок действий:

1. Сначала прошить свежий `codemaster_app.hex`.
2. Запустить application.
3. Записать имя и serial через кнопку **Прошить** без основного файла.
4. Повторно нажать **Прочитать конфигурацию**.

---

# 14. Важные файлы и адреса

| Файл/область | Назначение |
|---|---|
| `codemaster_bootloader.hex` | bootloader |
| `codemaster_app.hex` | основная application firmware |
| `codemaster_app.bin` | бинарная application firmware |
| `0x08000000` | bootloader |
| `0x08008000` | начало application |
| `0x0803D000` | CRC32 metadata application |
| `0x0803D800` | конфигурация |
| `0x0803E000` | триггеры |

Для мастера основной порядок всегда такой:

```text
Новая плата:
  bootloader → application → BOOT0=0 → настройка имени/serial

Рабочая плата:
  application → BOOT0=0 → настройка имени/serial
```
