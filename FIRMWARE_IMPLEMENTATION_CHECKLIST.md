# Чек-лист реализации firmware и конфигуратора

Полный рабочий чек-лист для подготовки, разработки, тестирования и выпуска улучшенной версии «Код Мастер».

Обозначения:

- `[ ]` — не выполнено;
- `[x]` — выполнено;
- `[~]` — выполняется;
- `P0` — блокирует безопасную эксплуатацию;
- `P1` — важная функциональность;
- `P2` — улучшение и подготовка к производству.

---

# 17. Финальные критерии допуска

Реализация считается готовой, если:

- [ ] повреждённая application не запускается;
- [ ] устройство восстанавливается после обрыва питания;
- [ ] конфигурация записывается без полной прошивки;
- [ ] конфигурация читается после обновления application;
- [ ] триггеры синхронизируются с UI;
- [ ] CAN-потери отображаются пользователю;
- [ ] USB CDC не зависает при отключённом ПК;
- [ ] прошивка занимает ожидаемое время;
- [ ] чтение занимает ожидаемое время;
- [ ] работает проверка после записи;
- [ ] кнопка подключения корректно сбрасывается после disconnect;
- [ ] работают все заявленные способы подключения;
- [ ] пройдены автоматические тесты;
- [ ] пройдены аппаратные тесты;
- [ ] документация соответствует фактической реализации;
- [ ] release содержит проверенные firmware и desktop artifacts.
